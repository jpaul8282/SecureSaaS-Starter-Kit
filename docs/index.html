PIECE 3 OF 4

3. Cryptographic Standards & Privacy

Defense-in-depth architectural protection safeguarding sensitive user and payment data:

  • AES-256-GCM at Rest: Galois/Counter Mode authenticated encryption with 96-bit unique IVs and 128-bit authentication tags.
  • TLS 1.3 in Transit: Ephemeral Diffie-Hellman key exchanges (ECDHE) with public key certificate pinning against MITM attacks.
  • Android Keystore HSM: Hardware-isolated StrongBox Keymaster protecting asymmetric private keys from memory dumps.
  • Zero-Knowledge Tokenization: PANs are tokenized directly in Stripe vaults without entering application RAM.

Security & Data Privacy Standards

Cryptographic guarantees, key protection, and GDPR / CCPA user rights enforcement.

Data at Rest: AES-256-GCM

Local data persistence uses NIST-standard AES-256-GCM. Every record is encrypted with a unique 96-bit initialization vector (IV) generated by SecureRandom and protected by a 128-bit authentication tag, detecting any unauthorized bit flipping.

Data in Transit: TLS 1.3 Strict

All remote requests enforce TLS 1.3 with Perfect Forward Secrecy. Ciphers are constrained to TLS_AES_256_GCM_SHA384 and TLS_CHACHA20_POLY1305_SHA256. Certificate pinning eliminates risk from compromised public Certificate Authorities.

Hardware Security: Android StrongBox

Keys are generated within the tamper-resistant hardware security module (HSM) on supported Android devices. Private keys cannot be extracted via physical probing, debugging, or system rooting.

User Privacy: GDPR & CCPA

Zero-knowledge customer records, Article 20 JSON data portability export, Article 17 Right to Erasure with automated purge pipeline, and CCPA Do-Not-Sell opt-out switches built natively into the UI.

Setup & Build Instructions

Step-by-step developer guide to compile, test, and host BillingHub.

Quick Terminal Setup

# 1. Clone repository
git clone https://github.com/organization/billinghub.git
cd billinghub

# 2. Configure .env secrets
cp .env.example .env

# 3. Add your Stripe Publishable Key
echo "STRIPE_PUBLISHABLE_KEY=pk_test_..." >> .env

# 4. Run automated test suite
gradle :app:testDebugUnitTest

# 5. Build debug APK
gradle :app:assembleDebug

GitHub Pages Hosting Configuration

This project documentation is hosted on GitHub Pages via two easy options:

  1. Branch Deployment: In GitHub repo settings > Pages, set source to main branch and folder to /docs.
  2. Automated CI/CD Workflow: The included .github/workflows/deploy-docs.yml automatically deploys documentation updates upon merge into main.
